# 13 — Open Questions

Items that need an owner decision or information not yet available. Each has a
recommended default so work can start; requirements that depend on an open question reference it.

| ID | Question | Why it matters | Recommended default | Status |
|---|---|---|---|---|
| OQ-001 | **Real-time stream sources.** The PC GOAL stream library (`PCGacc`/`RTIacc`, signature `0xFFF0FFFF`) and its `.flt` filter body format, certification status, stream events (`STREAMnnREF`, `TIMEREF`) and `@commands` are **not available**. ElvAcc files use signatures `0x4C41424C` and `0x4C42414C` (the ASCII tags "LBAL"/"LABL"). Which live sources must Multiplot.NET support at first release, and can the protocol specification be provided? | In-scope requirement FR-PLG-031 / FR-RT-050 cannot be implemented without it. | Deliver the host-side support and plugin API in release 1; implement the PC GOAL plugin when the protocol spec is supplied; ElvAcc plugin optional. | closed.  Ignore the PC GOAL stream library capability.   |
| OQ-002 | **Group (DB_DIR) files.** Query/DB_DIR browsing is out of scope, but `OPEN … ASDATABASE`, group text files and the `DBPATH` search path are used by scripts. Keep loading group files from `DBPATH`? | FR-LOAD-003. | Keep reading group files (and `DBPATH` search); drop only the Query tool. | Closed.  Drop only the Query tool. |
| OQ-003 | **Image export formats.** Which raster formats (BMP, JPEG, GIF, TIFF, PNG) should be offered? Add SVG/PDF as a replacement for EMF/printing?
