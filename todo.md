- [x] Delete all marker types except events.  The event markers should only require a timestamp and text.  Regardless of the scale of the plot, the marker should place a vertical line at the timestamp and then add text either at the top or bottom of the plot along side the vertical line.  The intention of this marker is to show when timed events have occurred relative to the changing values of the plotted parameters.  When the plot is being updated in real-time, the event marker should follow the associated timestamp and disappear from the plot window if this timestamp is not shown.  The marker menu and dialog box must be changed to show this new marker scheme.  The documents must be updated to show how the makers operate and add a section that details what they do and examples of how to add markers.  The markers shall still be loaded from an external file or shall be documented in the appropriate section of the header of the data file.  The markers must work in either the sun_multitime64 or parquet formatted data files.

- [x] Fix autoscaling of the axes. It is unclear when autoscaling is on or off, and during real-time plotting a refresh appears to autoscale the plot even when autoscaling is turned off. Eliminate the existing autoscaling functions and keep only two: autoscaling the time axis (X) and autoscaling the value axis (Y). Autoscaling can be ignored for plots without a time axis, except keep the command that autoscales both axes to include all existing values on the plot (also the Home key). That autoscale happens once, so that during real-time plotting the time axis shifts to the left while the value axis keeps its scale.
  - Implemented as two per-plot switches with check marks: *Axis → Auto Scale X (Time Axis)* and *Axis → Auto Scale Y (Value Axis)* (also in the plot right-click menu; script `AUTOSCALE X|Y|XY [ON|OFF]`; INI `AutoScaleX` / `AutoScaleY`; new plots start with both on).
  - Auto Scale X on: the time axis spans all data and grows with new real-time data. Off: the visible time span is kept and slides with the newest data (curves shift left); a view of older data stays put.
  - Auto Scale Y on: the value axes fit the data in the visible time range (refit on refresh and on time-range changes). Off: the value axes keep their scale during real-time updates.
  - Zoom, pan, zoom box, mouse wheel, Fix X / Fix Y and Revert Scales switch the affected axis's autoscaling off, so a refresh never undoes a manual range.
  - *Axis → Auto Range X/Y Once* (Home, `RESCALE`) fits both axes once to all values and switches both autoscale switches off.
  - Removed: *Auto Y on Change in X* (`FIXXAUTOY`), *Sliding Scales* (`TIMESLIDE`), the one-shot *Auto Range X* / *Auto Range Y*. `FIXX AUTO` / `FIXY AUTO` now mean `AUTOSCALE X|Y ON`. Plots without a time axis (X-Y, tabular) keep their scales on refresh.
  - Documented in the user guide (*Plot windows → Scales and autoscaling*, *Real-time operation*, *Scripts*) and requirements FR-PLT-017.
